# Unix Timestamp Converter

A simple web app that converts Unix timestamps into **human-readable UTC and local time** using your browser's timezone.

> **Made with Love by [SIRTOOLZ](https://twitter.com/sirtoolz)**  
> Join our [Telegram Community](https://t.me/sirtoolzalpha)

---

## Features

- Input any Unix timestamp
- Instantly displays:
  - UTC time
  - Your local time (browser-based)
- Clean UI and mobile-friendly
- Hosted for free on Render
